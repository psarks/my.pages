How to read the pitch

⚽ The ball
Whoever has it is the agent working right now.
Flying dots
Businesses, colored by type: car wash, coffee shop, ice cream, nail salon.
Numbers by the coaches
Leads each coach signed from the same checked businesses. Strict: 4.5+ stars, zero ads. Loose: 4.0+ stars, fewer than 3 ads. Hunter: no website or an outdated one. The lists overlap, so they don't add up.
Big screen
The logbook: every business the scout has found so far.
Ad board
The Meta Ad Library, where I count each business's ads by hand.
Goals
A business that became a client: I made their ad or website.

Live commentary⚽ On the ball: Secretary

    The squad

    Each agent is a small Python file with one job. The manager runs them in order with one command, and the coaches all read the same logbook.

    MGR

    Manager

    run_all.py

    Checks the backlog brake, then decides: scout something new or work the pile.

    SCT

    Scout

    researcher_agent.py

    Searches Google Places and adds new businesses to the logbook. Skips any it has seen before.

    CHK

    Ad checker

    ad_checker.py

    Opens the Meta Ad Library and asks me for the count. Meta doesn't allow bots, so a person does this step.

    STR

    Strict coach

    prospector_agent.py

    Signs businesses rated 4.5 or higher that run zero ads.

    LSE

    Loose coach

    prospector_agent.py

    Signs businesses rated 4.0 or higher with fewer than 3 ads.

    HNT

    Website hunter

    prospector_agent.py

    Signs the ones with no website or an outdated one.

    SEC

    Secretary

    notify.py

    Emails me the match summary when the run ends.
